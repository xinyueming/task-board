# 任务看板系统 (Kanban)

一个纯前端、单文件、可离线运行的任务看板应用，用 HTML + CSS + JavaScript 编写，无需任何构建工具或后端。

## ✨ 特性

- **四列看板**：待处理 → 处理中 → 已完成 → 已取消，支持拖拽移动任务、实时更新各列计数。
- **本地存储**：所有任务数据保存在浏览器 `localStorage`，关闭页面后不丢失。
- **任务管理**：新建、编辑、删除任务；每条任务包含标题、描述、来源、状态、取消原因和时间戳。
- **回收站**：删除的任务先移入回收站，7 天后自动清除，支持恢复或彻底删除。
- **数据看板**：顶部统计栏实时展示各状态数量与占比。
- **导出 CSV**：一键导出全部任务为 CSV 文件。
- **响应式布局**：桌面 4 列，平板 2 列，手机单列，移动端友好。

## 🚀 使用

直接用浏览器打开 `kanban.html` 即可，无需安装、无需服务器。

```bash
# 或克隆后本地预览
git clone https://github.com/xinyueming/task-board.git
# 用浏览器打开 kanban.html
```
